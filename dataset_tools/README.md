# K230 数据集自动标注工具

一键工作流：手机拍照 → 自动标注 → 手动修正 → 打包上传训练。

## 目录约定

- **输入照片** 固定放到 `C:\Users\pc\Desktop\p\`
- **输出数据集** 在本目录 `dataset/` 下，每次运行自动覆盖

## 一键启动

双击 `开始.bat`，按提示选数字：

```
[1] Auto-label   自动标注 p\*.jpg → dataset/
[2] Manual fix   手动检查/修正每张图
[3] Pack ZIP     生成 dataset_for_aicube.zip
[4] Clear        清空 dataset 文件夹
[Q] Quit
```

典型流程：拍照 → 复制到 `p\` → 运行 1 → 运行 2 改错 → 运行 3 上传。

## 多类别支持

要识别多种物体？打开 `config.py`，在 `CLASSES` 列表里加 dict：

```python
CLASSES = [
    {
        "name":        "plate",
        "hsv_lower":   np.array([10,  30,  80]),
        "hsv_upper":   np.array([35, 200, 240]),
        "min_ratio":   0.005,
        "max_ratio":   0.6,
        "kernel":      25,
        "multi_boxes": False,   # 每张图只有 1 个 plate
    },
    {
        "name":        "ball",
        "hsv_lower":   np.array([20, 100, 100]),
        "hsv_upper":   np.array([35, 255, 255]),
        ...
        "multi_boxes": True,    # 一张图可能有多个 ball
    },
]
```

自动标注、手动修正、打包脚本都会自动跟着读，**不用动其他文件**。

## labelfix 详细使用说明

### 什么时候用
跑完 `[1] Auto-label` 后，进度条会告诉你有几张 `[WARN] NO BOX`（自动没认出来）。这时启动 labelfix 来手动补/改。

### 启动后看到什么
- **顶部黑条**：`[3/18] img_0003.jpg | SUSPICIOUS | susp:18 | boxes:1`
  - `[3/18]` = 当前是 18 张待修中的第 3 张
  - `SUSPICIOUS` = 当前在 "只看问题图" 模式
  - `boxes:1` = 当前图已有 1 个框
- **第二条（带颜色高亮）**：所有类别按 `[1]plate [2]ball ...` 排列。**当前激活的类别会被它自己的颜色填充背景**，其他类别只显示文字。
- **底部黑条**：所有快捷键速查表。

### 操作键

| 键 | 作用 |
|---|---|
| **左键拖拽** | 画一个**当前类别**的新框（旧框不会被覆盖） |
| **右键点击** | 删除被点中的框（小框优先，便于在大框里删小框） |
| **1 ~ 9** | 切换当前类别（最多 9 类） |
| D / → | 下一张（自动保存当前图） |
| A / ← | 上一张（自动保存当前图） |
| Z | 撤销最后画的框 |
| X | 清空当前图所有框 |
| S | 跳到下一个问题图（跳过已经修好的） |
| F | 切换 "只看问题图 ↔ 全部图" |
| Q / ESC | 退出（自动保存） |

### 推荐工作流

**单类别**（比如只识别 plate）：
1. 启动时直接是 `SUSPICIOUS` 视图，逐张按 `D` 翻
2. 看到框不对的：按 `X` 清掉，重新拖一个
3. 没框的：直接拖一个
4. 翻完一遍后按 `F` 切到 `ALL`，快速扫一眼有没有漏改的
5. 按 `Q` 退出

**多类别**（比如 plate + ball 同时识别）：
1. 看 config.py 里 `CLASSES` 列表的顺序，记住 `1=plate`、`2=ball` ...
2. 进图后，**先看顶部类别条**，确认当前类别（高亮的那个）
3. 同一张图里有多个物体：
   - 按 `1` → 拖框给 plate
   - 按 `2` → 拖框给 ball
   - 多少个就拖多少个
4. 删错的框：右键点它（不需要切类别，右键自动认）
5. 翻页前不用做任何确认，`D` 一按当前所有框都进 XML

### 可疑判定逻辑
默认把这些图当 **可疑**：
- 完全没框
- 任意一个框面积 < 整图 0.5%（可能是误检小噪点）
- 任意一个框面积 > 整图 60%（可能把整画面框进去了）

阈值在 `config.py` 的 `SUSPICIOUS_MIN/MAX`。觉得管太严就调宽。

### 容易踩的坑
- **改了框之后忘记翻页就退出** → 没事，按 Q 也会保存当前图
- **多类别时类别条没注意** → 拖出来的框颜色不对就按 `Z` 撤销，切对类别再拖
- **手抖画了个超小框** → < 10×10 像素的框会被自动忽略，不用管
- **想保留旧框 + 加新框** → 直接拖新框就行，不要按 X

## 调参指南（识别效果不好时）

打开 `config.py`：

| 参数 | 调整方向 |
|---|---|
| `hsv_lower / hsv_upper` | 颜色检测不到 → 扩大范围 |
| `kernel` | 框碎掉 → 调大；框边界粘背景 → 调小 |
| `min_ratio` | 误检小物体 → 调大 |
| `max_ratio` | 把整画面当目标 → 调小 |

## AI Cube 上传

`dataset_for_aicube.zip` 上传到 [勘智 AI Cube](https://www.kendryte.com/) → 点训练。

ZIP 内部结构（已按 AI Cube 要求做好，不需要重新压）：
```
images/
xml/
labels.txt
```

打包前会自动：
- 检查 image / xml 配对完整性
- 统计每类样本数
- 列出空 XML（没框的图）
- 备份上次的 ZIP（带时间戳，防止训练好的批次被覆盖）
